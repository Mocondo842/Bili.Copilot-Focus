Bili.Copilot-Focus 安装说明（x64 侧载包）
========================================

包内文件
--------
  Install-Focus.cmd                       ← 双击这个（推荐）
  Install-Focus.ps1                       安装脚本本体
  BiliCopilot.UI_<版本>_x64.msix          主程序（已签名）
  Microsoft.WindowsAppRuntime.1.8.msix    x64 运行时依赖
  focus-sideload.cer                      本 fork 的签名证书
  安装说明.txt                            本文件

方式一：双击 Install-Focus.cmd（推荐）
--------------------------------------
  1. 先把 zip **完整解压**到一个文件夹（不要在压缩包预览里直接双击）；
  2. 双击 Install-Focus.cmd；
  3. 出现 UAC 弹窗点「是」，安装会在新开的管理员窗口里继续，按提示按任意键关窗。

  为什么用它：cmd 包装器给 powershell 显式加了 -ExecutionPolicy Bypass，并且命令结束后
  一定 pause——所以不会出现「窗口一闪就没了」。用右键「使用 PowerShell 运行」时，
  执行策略或系统安全提示可能拦住脚本，窗口就会一闪而过。

方式二：管理员 PowerShell 手动跑脚本
------------------------------------
  先进入包所在目录，再执行（注意 -File 后面是脚本路径；不在该目录时必须写完整路径）：

    cd C:\Users\你\Downloads\BiliCopilot-Focus_<版本>_x64
    powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Focus.ps1

  或者一条命令给完整路径：

    powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\你\Downloads\BiliCopilot-Focus_<版本>_x64\Install-Focus.ps1"

方式三：手动安装（不用脚本）
----------------------------
  1. 先信任证书：双击 focus-sideload.cer →
       「安装证书」→ 存储位置选「本地计算机」→
       「将所有的证书都放入下列存储」→ 浏览 →「受信任的根证书颁发机构」→ 完成。
     会弹一次安全警告，点「是」。
  2. 双击 Microsoft.WindowsAppRuntime.1.8.msix 装依赖（已装过或系统里已有更新版本时跳过）。
  3. 双击 BiliCopilot.UI_<版本>_x64.msix 装主程序。

  ⚠ 第 1 步不能省：这是自签名包，证书没进受信任根，Windows 会直接拒绝安装
    （提示 0x800B0109 /「证书链无法验证」）。信任一次即可，以后同一个证书签的新版本
    不用再信任——所以这个证书会长期不变。

安装时可能出现的两条「坏消息」（都不影响安装）
----------------------------------------------
  · 「Windows 无法安装程序包 Microsoft.WindowsAppRuntime.1.8_8000.x… 因为已安装更高版本
     8000.y」——系统里的 Windows App Runtime 比包里带的新，安装器会跳过依赖继续装主程序。
  · 「证书导入失败」——大概率是这张证书之前已经信任过；只有当主程序安装失败并报
     0x800B0109 时，才需要按方式三第 1 步手动信任一次。

为什么需要证书
--------------
  侧载（sideload）的 MSIX 必须是签过名的，个人 fork 不可能买商业代码签名证书，
  只能用自签名证书。它只用于让 Windows 确认「这个包没被改过」，不涉及任何网络信任。

升级
----
  新版本 msix 的文件版本号更高，直接再跑一遍安装脚本即可覆盖安装；不必先卸载。
  版本号相同时才需要卸载重装（脚本会提示当前已装版本与本包版本）。

常见问题
--------
  · 双击后窗口一闪而过：改用同目录的 Install-Focus.cmd。
  · UAC 弹窗没看到：它有时藏在其他窗口后面；也可能被安全软件拦了，改用方式三手动装。
  · 安装报 0x800B0109 / 证书链错误：按方式三第 1 步手动信任证书。
  · 安装报版本冲突：机器上已有同版本或更高版本（设置 → 应用 → 哔哩助理 → 卸载后再装）。
