Bili.Copilot-Focus 安装说明（x64 侧载包）
========================================

包内文件
--------
  BiliCopilot.UI_<版本>_x64.msix          主程序（已签名）
  Microsoft.WindowsAppRuntime.1.8.msix    x64 运行时依赖
  focus-sideload.cer                      本 fork 的签名证书
  Install-Focus.ps1                       安装脚本（推荐用这个）
  安装说明.txt                            本文件

推荐做法：一条命令装完
---------------------
  1. 解压到任意目录（路径别带特殊字符就行）；
  2. 在解压出来的文件夹里，右键 Install-Focus.ps1 →「使用 PowerShell 运行」；
     或者：开始菜单搜 PowerShell → 右键「以管理员身份运行」→ cd 到该目录 → 执行
         powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Focus.ps1
  3. 看到「安装完成」后按任意键关窗。

  脚本会依次：信任证书 → 装运行时依赖 → 装主程序。它不会"闪一下就没了"：
  没有管理员权限时会请求提权并把提示留在窗口里，失败也会把原因显示出来。

手动安装（不想用脚本时）
-----------------------
  1. 先信任证书：双击 focus-sideload.cer →
       「安装证书」→ 存储位置选「本地计算机」→
       「将所有的证书都放入下列存储」→ 浏览 →「受信任的根证书颁发机构」→ 完成。
     会弹一次安全警告，点「是」。
  2. 双击 Microsoft.WindowsAppRuntime.1.8.msix 装依赖（已装过可跳过）。
  3. 双击 BiliCopilot.UI_<版本>_x64.msix 装主程序。

  ⚠ 第 1 步不能省：这是自签名包，证书没进受信任根，Windows 会直接拒绝安装
    （提示"证书链无法验证"或"不受信任"）。信任一次即可，以后升级同一个证书签的
    新版本不用再信任——所以这个证书会长期不变。

为什么需要证书
--------------
  侧载（sideload）的 MSIX 必须是签过名的，而个人 fork 不可能买商业代码签名证书，
  只能用自签名证书。它只用于让 Windows 确认"这个包没被改过"，不涉及任何网络信任。

升级
----
  新版本的 msix 文件版本号更高，直接跑一遍 Install-Focus.ps1 即可覆盖安装；
  不需要先卸载（版本号相同时才需要 -ForceUpdateFromAnyVersion，脚本已内置重试）。

常见问题
--------
  · 窗口一闪而过：说明你没用 Install-Focus.ps1，用的可能是旧脚本；本脚本会留住窗口。
  · UAC 弹窗没看到：它有时藏在其他窗口后面；也可能被安全软件拦了，改用手动安装。
  · 安装报 0x800B0109 / 证书链错误：证书没进受信任根，回到手动安装第 1 步。
  · 安装报版本冲突：机器上已有同版本或更高版本，等新版本或先卸载旧的
       （设置 → 应用 → 哔哩助理 → 卸载）。
